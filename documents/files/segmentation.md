# InSAR 矩阵分割

从动态 N×N 相关系数矩阵中检测沿主对角线的连续块边界。本文档按三条路线组织：**daninet 方案**（`daninet/edge`，合成数据，置顶）、SVM 历史基线、CNN 当前主线（真实数据）。各路线的数字来自各自工件，不可横向混比。

> 素材来源：`workspace/corr-edge-detection/`（`SVM_HISTORY_TECHNICAL_DOCUMENT.md`、`CNN_TECHNICAL_DOCUMENT.md`、`TECHNICAL_REPORT.md`、`README.md`）。历史 SVM 代码位于该仓库提交 `1658ac7` 的 `svm/`，当前工作树不再包含。

## 一、daninet 方案（`daninet/edge` · 2026-10-19 首批结果）

来源：`daninet/runs/edge_ensemble3_notta/{metrics,evaluation,decode_eval}.json`、`daninet/out/edge_segmentation/summary.json`。合成数据训练，非真实数据。

| 项 | 内容 |
| --- | --- |
| 输入 | N×N 相关矩阵，5 通道（`normalized_gradient_svd` 特征模式） |
| 输出 | 长度 N−1 的逐候选边界判定 |
| 网络结构 | 多尺度残差骨干：in 5 / stem 16 / hidden 128 × 5 块，head 64（8 组），深监督侧头 [1, 3] |
| 训练配置 | 合成生成器：尺寸 14/17（未见尺寸 25），最小块宽 2，最多 4 个边界；L 训练 [9, 16, 36, 121]，测试 [9, 16, 25, 36, 49, 121]；split seed 20260713 |
| 训练与模型 | **主模型 `edge_final_single`**：seed 20261019、60 epoch × 32768 合成矩阵、早停 epoch 24、11.3 min（chip 0）；另有 3 模型集成（`edge_s20260713/14/15`）作对照 |
| 权重位置 | `daninet/runs/edge_final_single/`（主模型）、`daninet/runs/edge_ensemble3_notta/`（集成评估） |
| 解码 | 最优 `min_block2/uniform`（相对 uniform 仅 +0.08pp，决策层已近最优）；阈值 14→0.55、17→0.60 |
| Test Exact（n=3968） | **0.6872**（单模型）；3 模型集成 0.6890 [0.6744, 0.7034] |
| Rect F1 / Boundary F1 | 0.813 / 0.839（集成 0.812 / 0.845） |
| 边界数 MAE | 0.320（集成 0.308：过分割 10.0% / 欠分割 14.9%） |
| 未见尺寸 25（n=960） | Exact 0.592（单模型）；集成 0.577，错误模式反转为过分割（over 37.3% / under 2.5%） |
| 延迟（17×17） | 单模型 0.11 ms · 3 模型集成 0.35 ms |

**按视数的 Exact**（主模型冻结测试）：L=9 → 31.2%，L=16 → 54.8%，L=25 → 66.5%，L=36 → 77.5%，L=49 → 86.0%，L=121 → **97.7%**。相干估计越稳，切分越准，单调上升。

**按最小块宽**（最优解码）：块宽 2 → 66.5%，3 → 70.0%，4 → 73.3%，5 → 66.3%，6 → 69.6%，7 → 67.5%，8 → **77.0%**。窄块（2–3）明显更难，块宽 5–7 反而回落，说明难点不只是「块小」，还有边界密度与块宽的耦合。

**按真实边界数**：1 → 69.6%，2 → 70.1%，3 → 61.8%，4 → **50.0%**。边界越多越难，4 边界时掉到随机水平附近。

**与 CNN 主线的差异**：本方案在**合成数据**上训练（可无限生成），CNN 主线在真实 2075 矩阵上训练；两者输出同为 N−1 边界向量，但数据分布不同，数字不可直接比较。待真实数据接入后才谈对齐。

**导出可视化**：`daninet/out/edge_segmentation/`（gallery.png、dataset_overview.png、36 张样本图，17×17，`summary.json` 记录导出子集 Exact 0.660 / Rect 0.783）。

## 二、SVM 方案（历史基线）

历史 `svm/` 目录下是**两条不同的路径**，不能当作同一个模型比较：

| 路径 | 任务 | 训练数据 | 输入 → 输出 |
| --- | --- | --- | --- |
| `train.py` + `classify.py` | 矩阵级二分类 | 程序生成的合成矩阵 | 矩阵 → 「有无分块结构」 |
| `train_boundary.py` + `evaluate_boundary.py` | 逐候选边界分类 | 带人工标签的真实数据 | 矩阵 → N−1 个边界判定 |

只有第二条与当前 CNN 任务可比；矩阵级 SVM 只能回答「是否存在分块」，给不出边界位置。

### 2.1 共同特征基础

`svm/features.py` 把任意方阵压成 **24 维**向量（先做 (C+Cᵀ)/2 对称化）：

| 组别 | 维数 | 内容 |
| --- | --- | --- |
| 非对角元素统计 | 6 | 均值、标准差、偏度、峰度、10/90 分位数 |
| 特征值谱 | 5 | 最大特征值、条件数、前三占比、首二 gap 比、有效秩 |
| SPD 对角 profile | 6 | 最大值、均值、标准差、>0.3 计数、90/50 分位 |
| 行/列均值不连续性 | 4 | 行均值与列均值的标准差、极差 |
| 一阶梯度 | 3 | 水平/垂直差分最大值、二者比值 |

真实边界 SVM 在此基础上对每个候选位置 p 展开 **62 维局部边界特征**（左右上下文、对称差分、位置先验等），并做标准化与样本权重平衡。

### 2.2 训练与判定

- 核：RBF-SVM；模型选择走验证集网格（C、γ）。
- 阈值：按尺寸在验证集上分别校准；解码后经 `rectangles_from_boundary` 转成对角矩形。
- 评估口径与 CNN 完全一致（见「五、术语与指标」）。

### 2.3 局限与复现风险

1. 当前工作树**没有** SVM 源码与权重，只能从 `1658ac7` 用隔离 worktree 恢复。
2. 矩阵级与边界级结果不可混用；历史报告里的两类数字分属不同任务。
3. 62 维特征依赖手工阈值与标准化参数，换数据分布需要重新校准。
4. 合成 SVM 的数据生成器与真实边界 SVM 不是同一套，指标不能横向拼表。

## 三、CNN 方案（当前主线）

### 3.1 问题形式化

输入 C ∈ ℝᴺˣᴺ（近似对称），输出候选边界向量 b ∈ {0,1}ᴺ⁻¹：位置 p 表示索引 p−1 与 p 之间是否发生块边界。边界集合排序后转成对角矩形 (qᵢ, qᵢ₊₁)²。二维块检测因此转成一维多标签边界检测。

### 3.2 输入特征（5 通道）

原始矩阵、排除对角线后的矩阵内标准化、对称局部差分、前两个主特征向量绝对外积的谱先验——共 5 通道，按同尺寸 batch 组织。

### 3.3 网络与损失

- **骨干**：dilation 1/2/4 多尺度残差，宽度 32/64/128 三档；主头融合候选位置左右全局上下文；32/64 档另接深监督侧头。
- **损失**：Focal + Dice + `0.1` 非对称边界数约束（欠/过分割 2:1）+ `0.05` 块一致性正则 + `0.5` subset（最差位置）损失。
- **镜像等变正则**（默认 0.2）：z(C) ≈ reverse(z(flip(C)))，不依赖标签，降低随机种子方差。
- **可选两阶段**：先用全部 2075 个矩阵做掩码重建预训练，再 `--init-checkpoint` 微调。

### 3.4 数据与评估

- 2075 个真实矩阵，按**来源目录隔离**切成 76% / 10% / 14%（训练 767 / 验证 104 / 测试 140）；划分种子与训练种子解耦。
- 尺寸范围：当前只用 14×14、17×17，默认排除 32×32；训练中两尺寸等量 batch。
- 模型选择：验证集**分尺寸宏平均 Rect F1**；阈值按尺寸校准（单模型 14→0.55、17→0.65；集成另行校准）。
- 固定 10 个随机种子（`config/experiment_seeds.json`，2026-08-01 一次性生成），后续实验复用同一组。

### 3.5 当前结果

| 配置 | 模型数 | 阈值 14/17 | Test Exact | Rect F1 | Boundary F1 |
| --- | ---: | --- | ---: | ---: | ---: |
| 最佳单模型（seed06，镜像 0.3） | 1 | 0.55 / 0.65 | **0.6929** | 0.8960 | 0.8788 |
| 集成（镜像 0.2） | 10 | 0.50 / 0.55 | 0.6786 | 0.8923 | 见集成报告 |
| 混合集成（镜像 0.2+0.3） | 20 | — | 0.6786 | — | — |

单模型 10 种子均值：基线 `0.6064 ± 0.0292`；镜像 0.2 集成成员 `0.6457 ± 0.0239`。

> Exact Accuracy 对单个边界错误敏感，候选准确率又受负类主导，因此必须与 Boundary F1、Rect F1、边界数 MAE 一起读。

### 3.6 增强与合成数据

整块置换 / 镜像 / 对称噪声增强、因子模型合成块矩阵都已实现，但消融显示在当前数据分布下**反而掉点**，默认关闭。

## 五、术语与指标

| 术语 | 定义 |
| --- | --- |
| Exact Accuracy | 整条 N−1 边界向量与真值完全一致的样本比例 |
| Rect F1 | 边界→对角矩形，IoU≥0.5 最大二部匹配，逐样本 F1 均值 |
| Boundary F1 | 逐位置边界判定的 F1 |
| MAE | 预测/真值边界数绝对误差均值 |
| over / under rate | 预测边界数偏多 / 偏少的样本比例 |
| macro | 先按尺寸算指标再对尺寸算术平均 |
| subset 损失 | 每样本全部候选 Focal BCE 的最大值，batch 内平均 |
| 镜像等变 | ℒ(z(C), reverse(z(flip(C))))，无标签几何正则 |
