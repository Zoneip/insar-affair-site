InSAR 矩阵分割

SVM 历史基线、CNN 当前主线与 daninet 方案占位；置顶维护

updated 2026-10-23

← 返回文档列表 下载 Word

从动态 N×N 相关系数矩阵中检测沿主对角线的连续块边界。本文档按三条路线组织：daninet 方案（daninet/edge，合成数据，置顶）、SVM 历史基线、CNN 当前主线（真实数据）。各路线的数字来自各自工件，不可横向混比。

素材来源：workspace/corr-edge-detection/（SVM_HISTORY_TECHNICAL_DOCUMENT.md、CNN_TECHNICAL_DOCUMENT.md、TECHNICAL_REPORT.md、README.md）。历史 SVM 代码位于该仓库提交 1658ac7 的 svm/，当前工作树不再包含。

一、daninet 方案（daninet/edge · 2026-10-19 首批结果）

来源：daninet/runs/edge_ensemble3_notta/{metrics,evaluation,decode_eval}.json、daninet/out/edge_segmentation/summary.json。合成数据训练，非真实数据。

按视数的 Exact（主模型冻结测试）：L=9 → 31.2%，L=16 → 54.8%，L=25 → 66.5%，L=36 → 77.5%，L=49 → 86.0%，L=121 → 97.7%。相干估计越稳，切分越准，单调上升。

按最小块宽（最优解码）：块宽 2 → 66.5%，3 → 70.0%，4 → 73.3%，5 → 66.3%，6 → 69.6%，7 → 67.5%，8 → 77.0%。窄块（2–3）明显更难，块宽 5–7 反而回落，说明难点不只是「块小」，还有边界密度与块宽的耦合。

按真实边界数：1 → 69.6%，2 → 70.1%，3 → 61.8%，4 → 50.0%。边界越多越难，4 边界时掉到随机水平附近。

与 CNN 主线的差异：本方案在合成数据上训练（可无限生成），CNN 主线在真实 2075 矩阵上训练；两者输出同为 N−1 边界向量，但数据分布不同，数字不可直接比较。待真实数据接入后才谈对齐。

导出可视化：daninet/out/edge_segmentation/（gallery.png、dataset_overview.png、36 张样本图，17×17，summary.json 记录导出子集 Exact 0.660 / Rect 0.783）。

二、SVM 方案（历史基线）

历史 svm/ 目录下是两条不同的路径，不能当作同一个模型比较：

路径任务训练数据输入 → 输出
train.py + classify.py矩阵级二分类程序生成的合成矩阵矩阵 → 「有无分块结构」
train_boundary.py + evaluate_boundary.py逐候选边界分类带人工标签的真实数据矩阵 → N−1 个边界判定

只有第二条与当前 CNN 任务可比；矩阵级 SVM 只能回答「是否存在分块」，给不出边界位置。

2.1 共同特征基础

svm/features.py 把任意方阵压成 24 维向量（先做 (C+Cᵀ)/2 对称化）：

组别维数内容
非对角元素统计6均值、标准差、偏度、峰度、10/90 分位数
特征值谱5最大特征值、条件数、前三占比、首二 gap 比、有效秩
SPD 对角 profile6最大值、均值、标准差、>0.3 计数、90/50 分位
行/列均值不连续性4行均值与列均值的标准差、极差
一阶梯度3水平/垂直差分最大值、二者比值

真实边界 SVM 在此基础上对每个候选位置 p 展开 62 维局部边界特征（左右上下文、对称差分、位置先验等），并做标准化与样本权重平衡。

2.2 训练与判定

  • 核：RBF-SVM；模型选择走验证集网格（C、γ）。
  • 阈值：按尺寸在验证集上分别校准；解码后经 rectangles_from_boundary 转成对角矩形。
  • 评估口径与 CNN 完全一致（见「五、术语与指标」）。

2.3 局限与复现风险

  1. 当前工作树没有 SVM 源码与权重，只能从 1658ac7 用隔离 worktree 恢复。
  2. 矩阵级与边界级结果不可混用；历史报告里的两类数字分属不同任务。
  3. 62 维特征依赖手工阈值与标准化参数，换数据分布需要重新校准。
  4. 合成 SVM 的数据生成器与真实边界 SVM 不是同一套，指标不能横向拼表。

三、CNN 方案（当前主线）

3.1 问题形式化

输入 C ∈ ℝᴺˣᴺ（近似对称），输出候选边界向量 b ∈ {0,1}ᴺ⁻¹：位置 p 表示索引 p−1 与 p 之间是否发生块边界。边界集合排序后转成对角矩形 (qᵢ, qᵢ₊₁)²。二维块检测因此转成一维多标签边界检测。

3.2 输入特征（5 通道）

原始矩阵、排除对角线后的矩阵内标准化、对称局部差分、前两个主特征向量绝对外积的谱先验——共 5 通道，按同尺寸 batch 组织。

3.3 网络与损失

  • 骨干：dilation 1/2/4 多尺度残差，宽度 32/64/128 三档；主头融合候选位置左右全局上下文；32/64 档另接深监督侧头。
  • 损失：Focal + Dice + 0.1 非对称边界数约束（欠/过分割 2:1）+ 0.05 块一致性正则 + 0.5 subset（最差位置）损失。
  • 镜像等变正则（默认 0.2）：z(C) ≈ reverse(z(flip(C)))，不依赖标签，降低随机种子方差。
  • 可选两阶段：先用全部 2075 个矩阵做掩码重建预训练，再 --init-checkpoint 微调。

3.4 数据与评估

  • 2075 个真实矩阵，按来源目录隔离切成 76% / 10% / 14%（训练 767 / 验证 104 / 测试 140）；划分种子与训练种子解耦。
  • 尺寸范围：当前只用 14×14、17×17，默认排除 32×32；训练中两尺寸等量 batch。
  • 模型选择：验证集分尺寸宏平均 Rect F1；阈值按尺寸校准（单模型 14→0.55、17→0.65；集成另行校准）。
  • 固定 10 个随机种子（config/experiment_seeds.json，2026-08-01 一次性生成），后续实验复用同一组。

3.6 增强与合成数据

整块置换 / 镜像 / 对称噪声增强、因子模型合成块矩阵都已实现，但消融显示在当前数据分布下反而掉点，默认关闭。

四、无监督基线：DP 分段（2026-10-21 提出，10-22 同集复核）

动机：用户提出「相关度离主对角线越近越相干，只想分割对角矩阵」，需要一个不依赖训练的对照。

方法（无需训练、无需标签）：

  1. 切点得分 s(k) = 跨过候选 k、且 |i−j| ≤ 2 的 |γ| 均值（越低越像边界）
  2. 约束：相邻切点间隔 ≥ 2（最小块宽）
  3. DP：约束下选 K 个低分切点（全局最优，N ≤ 17 毫秒级）
  4. K 的给法：oracle K（用真值，仅作代价上界）/ λ 惩罚自动选 K

同集对照（daninet/edge/compare_dp.py，同 seed 同批矩阵，每格 300 张 × 6 视数）：

结论：训练内 12/12 格、真实尺寸 N=10 6/6 格 CNN 全胜；N=25 基本持平但 CNN 计数 MAE 明显变大。真实 111 组数据应优先用 CNN，DP 保留为无监督兜底与交叉验证。早期「DP+oracle K 0.721 优于 CNN 0.687」是跨测试集比较，已作废。瓶颈在「边界数（模型选择）」而非切点定位。

五、数据门禁（daninet/edge/audit.py，SPEC-003）

对任意块矩阵集输出五层指标（结构 / 标签 / 物理 / 可辨识性 / 分布）与 A–D 分级，只读、CPU 可跑。三轮迭代：

轮次对象结果
迭代 1合成参考卡（1200 矩阵）grade A；近对角带 Exact 0.492 / AUC 0.915，全矩阵仅 0.033 / 0.615
迭代 2注入 9 类缺陷9/9 检出（标签漂移、h/v 冲突、重复矩阵冲突等）
迭代 3仿真真实集（182 矩阵）grade D；定位「组 0901 标注口径漂移」（55% vs 86%/69%）

关键修正：

  1. 模矩阵不保证 PSD（合成集自身 26% 违例），PSD 不能作 |γ| 硬门禁；
  2. 块信息只在近对角带，全矩阵统计会被稀释；
  3. L̂ 改用跨块均值 −0.02（q05 反演会高估 20×）；AUC 方向已修正。

真实数据尚未跑门禁，任何「合成 → 真实」的性能断言目前都不可用。接入真实 .mat 后需跑第 4 次（命令见 specs/SPEC-003-块矩阵数据门禁.md §8）。
